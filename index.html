À savoir

Les choses simplement.

Où restent mes conversations ?

Dans les sources et les dossiers locaux configurés par l’application. Cette page de présentation ne reçoit ni vos prompts, ni vos archives.

Comment capturer ChatGPT et Perplexity ?

Le projet utilise un bookmarklet, un favori exécuté sur le site concerné, sans extension. L’application locale doit être lancée. La capture dépend de la session et des conversations accessibles ; son exhaustivité n’est pas garantie.

Actualiser récupère-t-il les nouveaux messages en ligne ?

L’actualisation relit les sources locales. Pour récupérer les changements sur ChatGPT ou Perplexity, une nouvelle capture est nécessaire.

Puis-je utiliser l’application depuis cette page ?

Non. GitHub Pages héberge cette présentation statique. L’application actuelle utilise ses moteurs locaux ; cette page n’est pas une version hébergée de votre bibliothèque.
